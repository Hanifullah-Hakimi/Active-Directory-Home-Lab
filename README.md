# 🏢 Active Directory Home Lab

## 📌 Overview

Hands-on Active Directory home lab built using Windows Server and Windows client virtual machines. The lab focuses on user and group management, Organizational Units (OUs), Group Policy, DNS, file sharing, and basic Windows administration.

## 🛠️ Technologies

- Windows Server
- Windows 10/11
- Active Directory Domain Services (AD DS)
- DNS
- Group Policy (GPO)
- VirtualBox
- PowerShell

## 🧪 Lab Environment

- **Domain:** Hanif.local
- **Domain Controller:** Windows Server
- **Client:** Windows 10/11
- **Virtualization:** VirtualBox

## 🔧 Tasks Completed

- Installed and configured Active Directory Domain Services
- Created and managed domain users
- Created security groups
- Created Organizational Units (OUs)
- Added Windows client to the domain
- Configured Group Policy
- Configured DNS
- Created and configured shared folders
- Managed NTFS and share permissions
- Tested user access and permissions
- Used PowerShell for Windows administration

## 🔐 Security Skills Practiced

- Identity and Access Management (IAM)
- Least Privilege
- User and Group Management
- Access Control
- Group Policy
- Windows Security
- Authentication and Authorization
- Basic Windows troubleshooting
